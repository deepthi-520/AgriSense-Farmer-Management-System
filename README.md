# 🌱 AgriSense – Farmer Management System

AgriSense is a web-based Farmer Management System developed using Python and Django. It helps farmers manage their profiles, crops, farming expenses, and sales through a simple and user-friendly interface.

## 🚀 Features

- Farmer Registration and Login
- Farmer Dashboard
- Farmer Profile Management
- Crop Management (Add, View, Update, Delete)
- Farming Expense Management
- Crop Sales Management

## 🛠️ Technologies Used

- Python
- Django
- MySQL
- HTML
- CSS

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/deepthi-520/AgriSense-Farmer-Management-System.git
```

### 2. Navigate to the project

```bash
cd AgriSense-Farmer-Management-System
```

### 3. Create a virtual environment

```bash
python -m venv venv
venv\Scripts\activate
```

### 4. Install dependencies

```bash
pip install -r requirements.txt
```

### 5. Configure environment variables

Create a `.env` file in the project root with your Django secret key and MySQL database details. Never upload this file to GitHub.

### 6. Apply migrations

```bash
python manage.py migrate
```

### 7. Run the server

```bash
python manage.py runserver
```

Open http://127.0.0.1:8000/ in your browser.

## 🎯 Project Objective

To simplify farm record management by providing a centralized platform for managing farmer information, crops, expenses, and sales.
